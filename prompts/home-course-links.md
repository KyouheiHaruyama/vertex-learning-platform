# Home course cards link to the course page

## Goal

Selecting a course card on the home page navigates to that course's page at
`/courses/[slug]`. Today the "All Courses" section renders three hardcoded
placeholder courses that are not links and have no slug, so they cannot go
anywhere — the cards have to come from Sanity first.

Only the home page's course cards. No catalog page, no other route.

## Code and data checked

- `web/app/page.tsx` — `AllCourses` maps over a local `courses` array with a
  `CourseMark` built from initials and a hex background. `HomeCourseCard` takes
  `title`, `description`, `level`, `duration`, `moduleCount`, `mark`.
- `web/components/ui/home-course-card.tsx` — renders an `<article>`, no link.
- `web/sanity/queries.ts` — `COURSES_QUERY` already orders by
  `popular desc, _createdAt desc` and shares `courseCardFields`, which has
  everything the card needs **except** total duration.
- Verified against the live dataset that
  `math::sum(modules[].lessons[]->duration)` returns the right total —
  `nextjs-app-router-in-depth` gives 7169s, matching the 1h 59m the course page

- `web/app/design-system/page.tsx` uses `CourseCard`, not `HomeCourseCard`, so
  the component gallery is unaffected.

## Decisions and assumptions

1. **Three cards, matching the reference.** `design/vertex-home.png` shows three
   cards and a "View all courses" link. A new `HOME_COURSES_QUERY` slices
   `[0...3]` off the existing ordering rather than fetching all ten and
   discarding seven.
2. **The card mark is the course cover image.** The reference shows brand logos
   (Next.js, Docker, TypeScript) in a 76px rounded square. Sanity stores a
   `coverImage` per course and nothing else that could serve as a mark, so the
   cover fills that square. Seed covers are picsum placeholders, so the marks
   will read as photos until real cover art is uploaded — a content gap, not a
   layout change. Courses without a cover fall back to a neutral tile with the
   title's first letter.
3. **The whole card is the link.** "Selecting the card" is the requested
   interaction, and the reference shows no separate call to action on these
   cards.
4. **Hover state follows the existing tertiary-surface pattern.** The reference
   has no hover frame for this card, so reuse what the project already does on
   raised white surfaces: `hover:shadow-md` plus a slightly darker border. No
   new visual language.
5. **"View all courses" stays pointed at `/courses`,** which is still unbuilt
   and will 404 until it is. Unchanged by this task.

## Requirements

- Every card's title, summary, level, duration and module count comes from
  Sanity. No hardcoded course data remains in `app/page.tsx`.
- Clicking anywhere on a card navigates to `/courses/{slug}`. Cards whose slug
  is null are skipped rather than linked to a broken URL.
- The card is one link, not a link nested inside another interactive element,
  and its accessible name is the course title.
- Keyboard: the card is reachable by Tab and shows the focus outline.
- The rendered layout is unchanged from `design/vertex-home.png` apart from the
  marks now being cover images and the copy now being real course copy.

## Security

- The fetch happens in the server component through `sanityFetch`; the
  server-only Sanity client and its token stay on the server.
- `urlForImage` is token-free. `cdn.sanity.io` is already in
  `next.config.ts` `images.remotePatterns` from the course page work.
- No new environment variables, no writes, no client-side data access.

## Acceptance criteria

1. The home page shows three real courses from Sanity, most popular first.
2. Clicking a card lands on that course's page and the title matches.
3. The meta row shows the course's real level, total duration and module count;
   the duration equals the one shown on that course's own page.
4. Tabbing reaches each card and Enter follows it.
5. `app/page.tsx` contains no hardcoded course data.
6. `npm run typegen`, `npm run typecheck`, `npm run lint` and `npm run build`
   all pass.

## Manual test steps

1. `npm run dev`, open <http://localhost:3000/>.
2. The "All Courses" row shows three real courses, not "Docker Essentials" or
   "TypeScript Deep Dive".
3. Click the first card — it opens that course's page, and the H1 matches the
   card title.
4. Go back, compare the card's duration and module count with the meta row on
   the course page. They agree.
5. Tab from the "View all courses" link into the cards; each shows a focus
   outline, and Enter navigates.
6. Narrow to ~375px: the cards stack and nothing overflows.
